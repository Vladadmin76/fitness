# Fitness Coach

Веб-приложение для тренировок: разминка + основная тренировка, подобранные под
цель (проработка групп мышц или похудение), место занятий (дома/зал) и
доступный инвентарь. Работает в браузере, без регистрации — все данные
(настройки, история тренировок, личные рекорды) хранятся локально.

## Возможности

- Онбординг: цель → место → инвентарь (для дома, с сохранением в настройки).
- Подбор упражнений из открытой базы [wger](https://wger.de/) (мышцы,
  оборудование, описание техники, изображения) — с фильтром по доступному
  инвентарю.
- Схема тела с подсветкой целевой (красным) и вспомогательных (оранжевым)
  мышц для каждого упражнения.
- Прогрессия весов по методу двойной прогрессии: тот же вес, пока не
  достигнута верхняя граница повторений во всех подходах, затем — вес выше
  (для дома — следующая доступная гантель, иначе усложнение техники).
- Замена упражнения в зале (тренажёр занят/сломан/отсутствует) — альтернатива
  на ту же группу мышц.
- Таймер отдыха между подходами, личные рекорды, графики прогресса, стрик
  тренировок — история хранится в localStorage.
- Музыка во время тренировки: интернет-радио (SomaFM, без ключей) или
  плейлист по тегам energetic/workout (Jamendo, нужен бесплатный client_id).

## Запуск

```bash
npm install
npm run dev
```

## Музыка через Jamendo (опционально)

Радио (SomaFM) работает сразу. Чтобы включить плейлист Jamendo:

1. Зарегистрируйся на https://devportal.jamendo.com/ и получи бесплатный `client_id`.
2. Скопируй `.env.example` в `.env` и впиши `VITE_JAMENDO_CLIENT_ID`.

## Технологии

React + TypeScript + Vite, Tailwind CSS, React Router, Recharts. Данные
упражнений — публичный API wger (без авторизации, CC-BY-SA).
