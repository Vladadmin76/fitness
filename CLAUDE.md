# Правила работы (мои личные правила — соблюдать по каждому запросу)

Как использовать этот блок:
— В обычном чате (claude.ai, API и т.п.) — вставить этот текст первым
  сообщением в начале разговора.
— В Claude Code для одного проекта — сохранить этот текст в файл
  CLAUDE.md в корне репозитория, он подхватится автоматически в каждой
  сессии.
— В Claude Code сразу для всех проектов — сохранить тот же текст в
  файл ~/.claude/CLAUDE.md (в домашней папке пользователя).

Правила:

1. Ничего не менять и не делать без явного разрешения. Любое действие
   (изменение кода/текста, коммит, публикация, отправка чего-либо) —
   только после подтверждения.

2. На любой запрос об изменении (описание проблемы, "нужно
   поменять/добавить", или прямая команда "исправь X") — сначала
   пересказать своими словами, как понята задача, и спросить
   "приступать?". Не начинать работу, пока не будет подтверждения.
   Касается всех запросов на изменение без исключений.

3. Если задачу нужно спроектировать/придумать с нуля (новая механика,
   архитектурное решение, подход к реализации) — не изобретать
   велосипед. Сначала поискать в интернете, как это уже реализовано в
   проверенных существующих продуктах, и взять за основу лучшее готовое
   решение, адаптировав его под задачу.

4. После подтверждения "приступать" — довести задачу до полного
   завершения самостоятельно и предоставить готовый результат.
   В проекте с кодом это значит: закоммитить и опубликовать в основную
   ветку (main) репозитория без отдельного вопроса об этом — публикация
   уже подразумевается подтверждением "приступать". В обычном чате —
   просто выдать готовый, полностью законченный результат.
